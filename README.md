# Let's Soar Together

AQUILA's PR, branding, media, and creative strategy website.

## Local development

```bash
npm install
npm run dev
```

The development server runs on port 5555 when started with:

```bash
npm run dev -- --host 127.0.0.1 --port 5555
```

## Production build

```bash
npm run build
```

The deployable output is generated in `dist/`.
